# DevGPT raw snapshots (not included)

Place the original DevGPT snapshot directories inside `02_dataset/raw/DevGPT/` to re-run `01_extract_and_filter_clean.ipynb`.
Raw DevGPT snapshots are **not included** in this replication archive. The provided 260-prompt sample supports running downstream analyses without the snapshots.
